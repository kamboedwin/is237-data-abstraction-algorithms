IS 237 · Topic 3

Review Questions

Try each question before opening the suggested answer.

1. What is an array?
Suggested answer: An indexed collection of elements arranged in a sequence of logical positions.
2. Why is array access by a known index usually O(1)?
Suggested answer: Because the logical position can be identified directly without traversing earlier elements.
3. What is array traversal and what is its typical complexity?
Suggested answer: Visiting all elements, usually O(n).
4. Why can insertion in the middle of an array be O(n)?
Suggested answer: Later elements may need to shift to create space.
5. Why can deletion from the middle of an array be O(n)?
Suggested answer: Later elements may need to shift left to remove the gap.
6. What is a fixed-size array?
Suggested answer: An array whose capacity is chosen when it is created and does not grow in place.
7. What is a dynamic array?
Suggested answer: An array-like structure that can grow by allocating a larger backing array and copying elements when capacity is exhausted.
8. What is amortised analysis in the context of dynamic arrays?
Suggested answer: It considers the average cost over a sequence of operations, allowing occasional expensive resizes to be spread across many cheap appends.
9. What is a linked list?
Suggested answer: A collection of nodes where each node stores data and reference information connecting it to other nodes.
10. What does the head reference represent?
Suggested answer: A reference to the first node of a linked list.
11. Why is access by numerical position usually O(n) in a singly linked list?
Suggested answer: The structure normally must follow references from the head through preceding nodes.
12. Describe insertion at the beginning of a singly linked list.
Suggested answer: Create a node, point its next to the old head, then update head to the new node.
13. Why is insertion at the head O(1)?
Suggested answer: Only a constant number of references change when the head is already known.
14. Why is 'linked-list insertion is O(1)' an incomplete statement?
Suggested answer: Finding the target position may require O(n) traversal even if the relinking itself is O(1).
15. How is deletion performed after a predecessor is known?
Suggested answer: Change the predecessor's next reference so that it bypasses the node being removed.
16. What additional information does a doubly linked node store?
Suggested answer: A reference to the previous node as well as the next node.
17. What is a circular linked list?
Suggested answer: A linked structure where the last node connects back to an earlier node, often the head.
18. Give one application of a circular list.
Suggested answer: Round-robin scheduling or repeated turn-taking.
19. Compare memory overhead of arrays and linked lists.
Suggested answer: Arrays usually have lower per-element overhead; linked nodes require one or more reference fields.
20. When is an array likely to be preferable?
Suggested answer: When indexed access, compact storage or locality are important.
21. When can a linked list be attractive?
Suggested answer: When frequent structural insertions/deletions occur at already-known nodes and direct indexing is not central.
22. Explain why there is no universally best data structure.
Suggested answer: Different structures optimise different operations and involve trade-offs in time, memory, simplicity and access patterns.
