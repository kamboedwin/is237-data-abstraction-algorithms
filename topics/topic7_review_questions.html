IS 237 · Topic 7

Review Questions

Try each question before opening the suggested answer.

1. What is a tree?
Suggested answer: A hierarchical structure of nodes connected by edges, with a root and parent-child relationships.
2. What is the root?
Suggested answer: The distinguished top node of a rooted tree.
3. What is a leaf?
Suggested answer: A node with no children.
4. What is node depth?
Suggested answer: The number of edges on the path from the root to that node.
5. What is node height?
Suggested answer: The number of edges on the longest downward path from that node to a leaf.
6. What is a binary tree?
Suggested answer: A tree in which each node has at most two children.
7. Differentiate full, perfect and complete binary trees.
Suggested answer: Full: every node has 0 or 2 children. Perfect: all internal nodes have 2 children and leaves share one depth. Complete: all levels are full except possibly the last, filled left to right.
8. What is a skewed binary tree?
Suggested answer: A tree whose nodes repeatedly fall to one side, making its height approach n.
9. Give the visiting order of preorder traversal.
Suggested answer: Root, Left, Right.
10. Give the visiting order of inorder traversal.
Suggested answer: Left, Root, Right.
11. Give the visiting order of postorder traversal.
Suggested answer: Left, Right, Root.
12. Which ADT is naturally used by level-order traversal?
Suggested answer: A Queue.
13. What special result does inorder traversal give for a BST?
Suggested answer: Keys in sorted order.
14. What property defines a BST?
Suggested answer: Keys smaller than a node occur in its left subtree and larger keys in its right subtree, recursively.
15. What is BST search complexity in terms of height?
Suggested answer: O(h).
16. Why is balanced BST search typically O(log n)?
Suggested answer: A balanced tree keeps height proportional to log n.
17. Why can an ordinary BST degrade to O(n)?
Suggested answer: Insertion order can create a skewed tree of height proportional to n.
18. Describe BST insertion.
Suggested answer: Follow comparisons left or right until a null child location is found, then attach the new node.
19. What are the three BST deletion cases?
Suggested answer: Deleting a leaf, a node with one child, and a node with two children.
20. How can a BST node with two children be deleted?
Suggested answer: Replace its key with the inorder successor (or predecessor), then delete that replacement node from its original location.
21. What is the inorder successor used in deletion?
Suggested answer: The smallest key in the right subtree.
22. Why do self-balancing BSTs exist?
Suggested answer: To keep tree height logarithmic after updates and avoid skewed O(n) behaviour.
23. What is a binary heap?
Suggested answer: A complete binary tree satisfying a heap-order property.
24. Differentiate max-heap and min-heap.
Suggested answer: In a max-heap each parent is at least its children; in a min-heap each parent is at most its children.
25. Why can a binary heap be stored efficiently in an array?
Suggested answer: Its complete-tree shape fills levels from left to right with no structural gaps.
26. For zero-based heap indexing, what are the child formulas?
Suggested answer: left(i)=2i+1 and right(i)=2i+2.
27. What is the parent-index formula for a zero-based heap?
Suggested answer: floor((i-1)/2).
28. Describe max-heap insertion.
Suggested answer: Append at the next complete-tree position, then sift upward while the child exceeds its parent.
29. What is the complexity of heap insertion?
Suggested answer: O(log n).
30. What is the complexity of reading the maximum from a max-heap?
Suggested answer: O(1).
31. Describe ExtractMax.
Suggested answer: Save the root, move the final value to the root, shrink the heap and heapify down.
32. What is heapify down?
Suggested answer: Repeatedly swap a node with the larger appropriate child until heap order is restored.
33. What is the complexity of extracting the heap root?
Suggested answer: O(log n).
34. What ADT is commonly implemented with a heap?
Suggested answer: A priority queue.
35. What is a hash table?
Suggested answer: A key-value structure that uses a hash function to map a key toward a table index or bucket.
36. What is a collision?
Suggested answer: Two different keys map to the same initial table index.
37. How does separate chaining handle collisions?
Suggested answer: Each table position stores a bucket containing multiple entries.
38. How does linear probing handle collisions?
Suggested answer: It checks later table positions according to a probe sequence until an available/matching slot is found.
39. Why is a DELETED marker important in open addressing?
Suggested answer: Replacing a deleted item with EMPTY can break a probe chain and cause searches to stop too soon.
40. What is load factor?
Suggested answer: The number of stored entries divided by the number of table slots.
41. Why do hash tables resize?
Suggested answer: To control load factor and preserve short collision chains/probe sequences.
42. What is the average complexity of well-designed hash-table search?
Suggested answer: O(1) average/expected.
43. What is the worst-case hash-table search complexity?
Suggested answer: O(n) if collisions become extreme.
44. Which structure is best suited to sorted traversal?
Suggested answer: A BST, especially a balanced one.
45. Which structure is best suited to repeatedly retrieving the highest-priority item?
Suggested answer: A max-heap/priority queue.
46. Which structure is best suited to fast exact key lookup without sorted-order requirements?
Suggested answer: A hash table.
