IS 237 · Topic 8

Review Questions

Try each question before opening the suggested answer.

1. What is a graph?
Suggested answer: A data structure/model consisting of vertices and edges that represent entities and relationships.
2. What does G = (V,E) mean?
Suggested answer: V is the set of vertices and E is the set of edges.
3. What is vertex degree in an undirected graph?
Suggested answer: The number of incident edges connected to the vertex.
4. Differentiate indegree and outdegree.
Suggested answer: Indegree counts incoming directed edges; outdegree counts outgoing directed edges.
5. What is a path?
Suggested answer: A sequence of adjacent vertices/edges connecting one vertex to another.
6. What is a cycle?
Suggested answer: A path that returns to its starting vertex.
7. What is a connected component?
Suggested answer: A maximal connected subgraph in which vertices are mutually reachable.
8. Differentiate directed and undirected graphs.
Suggested answer: Directed edges have orientation; undirected edges represent two-way relationships.
9. What is a weighted graph?
Suggested answer: A graph whose edges carry numeric values such as distance, cost or time.
10. Why are trees a special type of graph?
Suggested answer: A tree is a connected acyclic graph.
11. What is an adjacency matrix?
Suggested answer: A V×V table indicating whether or with what weight pairs of vertices are connected.
12. What is an adjacency list?
Suggested answer: For each vertex, a collection of its adjacent neighbours/edges.
13. What is the space complexity of an adjacency matrix?
Suggested answer: O(V²).
14. What is the typical space complexity of an adjacency list?
Suggested answer: O(V+E).
15. When is an adjacency list particularly attractive?
Suggested answer: For sparse graphs where E is much smaller than V².
16. What advantage does an adjacency matrix have for edge lookup?
Suggested answer: Checking whether edge (u,v) exists is O(1).
17. What does BFS stand for?
Suggested answer: Breadth-First Search.
18. Which ADT does BFS use?
Suggested answer: A Queue.
19. How does BFS explore a graph?
Suggested answer: Level by level outward from the start vertex.
20. Why should BFS mark a vertex visited when it is first enqueued?
Suggested answer: To prevent multiple neighbours from adding the same vertex to the queue repeatedly.
21. What is BFS complexity with an adjacency list?
Suggested answer: O(V+E).
22. What is BFS complexity with an adjacency matrix?
Suggested answer: O(V²).
23. What shortest-path property does BFS provide?
Suggested answer: It finds shortest paths by number of edges in an unweighted/equal-weight graph.
24. How are BFS shortest paths reconstructed?
Suggested answer: Store a predecessor for each discovered vertex and follow predecessors backward from target to source.
25. What does DFS stand for?
Suggested answer: Depth-First Search.
26. Which structures can implement DFS?
Suggested answer: Recursion using the call stack or an explicit Stack ADT.
27. How does DFS explore a graph?
Suggested answer: It follows one branch deeply before backtracking.
28. What is DFS complexity with an adjacency list?
Suggested answer: O(V+E).
29. Why can recursive and iterative DFS visit in different orders?
Suggested answer: The order in which neighbours are processed or pushed can differ.
30. How can BFS/DFS traverse a disconnected graph completely?
Suggested answer: Start a new traversal from every still-unvisited vertex.
31. Why is a visited set important in graphs with cycles?
Suggested answer: It prevents infinite or repeated traversal of already explored vertices.
32. What is a sparse graph?
Suggested answer: A graph with relatively few edges compared with the O(V²) possible connections.
33. What is a dense graph?
Suggested answer: A graph containing many of the possible edges.
34. When does BFS fail to give minimum-cost paths?
Suggested answer: When edge weights differ; the fewest edges may not have the lowest total cost.
35. What problem does Dijkstra's algorithm solve?
Suggested answer: Single-source shortest paths in graphs with non-negative edge weights.
36. What is relaxation in Dijkstra's algorithm?
Suggested answer: Testing whether distance[u] + weight(u,v) improves the best known distance to v.
37. Which ADT is commonly used to select the next vertex in efficient Dijkstra implementations?
Suggested answer: A min-priority queue, usually implemented with a min-heap.
38. What is a common Dijkstra complexity with adjacency lists and a binary heap?
Suggested answer: O((V+E) log V).
39. Why must Dijkstra not be used blindly with negative edge weights?
Suggested answer: Its settled-vertex correctness assumption can fail when a later negative edge reduces an already settled distance.
40. Compare BFS and Dijkstra for unweighted graphs.
Suggested answer: BFS is sufficient and simpler; Dijkstra works but adds unnecessary priority-queue machinery.
41. Give one application of BFS.
Suggested answer: Examples: unweighted shortest paths, level-by-level exploration, degrees of separation.
42. Give one application of DFS.
Suggested answer: Examples: connected components, cycle-oriented exploration, deep traversal, maze/backtracking-style search.
43. How does Topic 8 reuse queues?
Suggested answer: BFS stores the frontier in a queue.
44. How does Topic 8 reuse stacks/recursion?
Suggested answer: DFS stores pending exploration in a stack or recursive call stack.
45. How does Topic 8 reuse heaps?
Suggested answer: Dijkstra can use a min-heap priority queue.
46. What is the main course-level lesson from graphs?
Suggested answer: Data representation strongly influences which algorithms are natural and efficient.
