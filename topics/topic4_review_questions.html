IS 237 · Topic 4

Review Questions

Try each question before opening the suggested answer.

1. What principle defines a stack?
Suggested answer: Last In, First Out (LIFO).
2. Name the five common stack operations.
Suggested answer: push, pop, peek/top, isEmpty and size.
3. What is stack underflow?
Suggested answer: Attempting to remove or inspect a top element when the stack is empty.
4. What is overflow in a fixed array stack?
Suggested answer: Attempting to push when no capacity remains.
5. How does an array stack identify the top?
Suggested answer: Using a top index.
6. What is the typical complexity of array-stack push/pop without resizing?
Suggested answer: O(1).
7. How is a linked stack commonly represented?
Suggested answer: The head node is treated as the top.
8. Why are linked-stack push and pop O(1)?
Suggested answer: Only the top reference and a constant number of links change.
9. Give three applications of a stack.
Suggested answer: Examples include function calls, recursion, undo, bracket matching, DFS and expression evaluation.
10. Why is a stack suitable for balanced-bracket checking?
Suggested answer: The most recent unmatched opening bracket must match the next closing bracket.
11. What principle defines a queue?
Suggested answer: First In, First Out (FIFO).
12. Where do enqueue and dequeue occur?
Suggested answer: Enqueue at rear; dequeue at front.
13. What is false overflow in a linear array queue?
Suggested answer: rear reaches the final array slot even though earlier slots are free after dequeues.
14. How does a circular queue avoid false overflow?
Suggested answer: Indexes wrap around and reuse freed positions.
15. What operation enables circular wrap-around?
Suggested answer: Modulo arithmetic.
16. Why can circular enqueue/dequeue be O(1)?
Suggested answer: They change indexes and one element without shifting all values.
17. Why does a linked queue keep both front and rear?
Suggested answer: To make dequeue at front and enqueue at rear both O(1).
18. What update is required when the last linked-queue item is removed?
Suggested answer: Both front and rear must become null.
19. What is a deque?
Suggested answer: A double-ended queue with insertion and deletion at both ends.
20. Name the four basic deque modification operations.
Suggested answer: insertFront, insertRear, deleteFront and deleteRear.
21. What is an input-restricted deque?
Suggested answer: Insertion is permitted at only one end; deletion is permitted at both.
22. What is an output-restricted deque?
Suggested answer: Deletion is permitted at only one end; insertion is permitted at both.
23. Give one queue application and explain FIFO suitability.
Suggested answer: Example: print jobs; earlier submissions are normally processed first.
24. Give one deque application.
Suggested answer: Sliding-window algorithms, work stealing or flexible buffering.
25. Why should Stack and Queue first be understood as ADTs?
Suggested answer: Their defining feature is behavioural rules; different data structures can implement the same behaviour.
26. How does understanding stacks prepare you for recursion?
Suggested answer: Recursive calls are stored and returned through a call stack.
