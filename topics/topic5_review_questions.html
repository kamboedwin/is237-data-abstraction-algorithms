IS 237 · Topic 5

Review Questions

Try each question before opening the suggested answer.

1. What is recursion?
Suggested answer: A technique in which a function solves a problem by calling itself directly or indirectly on a smaller or simpler instance.
2. What is iteration?
Suggested answer: Repeated execution controlled by a loop such as for or while.
3. Why is the call stack important in recursion?
Suggested answer: Each active recursive call stores a stack frame containing parameters, local state and the return point.
4. What is a base case?
Suggested answer: A case that can be answered directly without making another recursive call.
5. Why is a base case alone not enough to guarantee termination?
Suggested answer: Every recursive path must also make progress toward that base case.
6. What is the recursive case?
Suggested answer: The part that reduces the problem and makes one or more recursive calls.
7. Describe the two phases of recursive factorial execution.
Suggested answer: Descent creates calls; unwinding returns values and completes pending multiplication.
8. Compare the space complexity of ordinary recursive and iterative factorial.
Suggested answer: Recursive factorial uses O(n) call-stack space; the iterative version uses O(1) extra loop state.
9. Write the idea behind recursive array sum.
Suggested answer: Sum n elements by adding the final element to the sum of the first n-1 elements, with the sum of zero elements as 0.
10. What is the main difference between recursive and iterative binary search in space use?
Suggested answer: Both are O(log n) time, but recursive binary search uses O(log n) call-stack space while the iterative form uses O(1) extra space.
11. What is direct recursion?
Suggested answer: A function directly calls itself.
12. What is indirect or mutual recursion?
Suggested answer: Functions call one another in a cycle, so a function is reached again indirectly.
13. What is tail recursion?
Suggested answer: Recursion where the recursive call is the final operation and no work remains after it returns.
14. Why is ordinary factorial non-tail recursive?
Suggested answer: The multiplication by n remains pending after factorial(n-1) returns.
15. What is multiple or tree recursion?
Suggested answer: A recursive call makes more than one recursive call, producing a branching call structure.
16. Why is naive recursive Fibonacci inefficient?
Suggested answer: It repeatedly recomputes the same subproblems, producing exponential growth in calls.
17. What is memoisation?
Suggested answer: Storing previously computed subproblem results so repeated calls can reuse them.
18. What time complexity does memoised Fibonacci achieve?
Suggested answer: O(n) time, with O(n) stored results.
19. What is tail-call optimisation?
Suggested answer: A compiler/runtime optimisation that reuses a stack frame for a tail call instead of growing the call stack.
20. Does tail recursion guarantee constant stack space in every language?
Suggested answer: No. The runtime must actually perform tail-call optimisation.
21. Give three problems where recursion is natural.
Suggested answer: Examples include tree traversal, divide-and-conquer sorting and backtracking.
22. Give two situations where iteration is often preferable.
Suggested answer: Simple linear repetition and very deep repetition where stack growth is risky.
23. What is stack overflow in recursive computation?
Suggested answer: Failure caused by creating more active call frames than the runtime call stack can support.
24. How can general recursion be converted to iteration?
Suggested answer: Represent pending work explicitly, often using variables or an explicit Stack ADT.
25. Why can recursion make correctness reasoning easier?
Suggested answer: When the problem itself is recursively structured, the recursive method mirrors its decomposition.
26. Which upcoming sorting algorithms naturally use recursion?
Suggested answer: Merge sort and quicksort.
