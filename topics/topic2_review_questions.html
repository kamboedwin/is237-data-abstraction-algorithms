Review Questions

Try each question before opening the suggested answer.

1. What is abstraction in computer science?
Suggested answer: The deliberate hiding of unnecessary lower-level details so a user can work with essential behaviour at a suitable level.
2. Why does abstraction help manage complexity?
Suggested answer: It limits the amount of detail considered at one time and lets programmers reason about components through clear interfaces.
3. Define an Abstract Data Type (ADT).
Suggested answer: A logical description of values, permitted operations and the behavioural rules governing those operations.
4. What is the main difference between an ADT and a data structure?
Suggested answer: An ADT specifies what behaviour is provided; a data structure is a concrete representation used to implement that behaviour.
5. Can the same ADT have more than one implementation?
Suggested answer: Yes. Different data structures can satisfy the same ADT contract.
6. What is an interface?
Suggested answer: The public operations that clients are allowed to use together with their expected behaviour.
7. What is an implementation?
Suggested answer: The hidden internal representation and procedures that make interface operations work.
8. Why is representation independence valuable?
Suggested answer: It allows internal implementation changes without requiring client code to change, provided the contract remains the same.
9. What is a precondition?
Suggested answer: A condition that must be true before an operation is validly called.
10. What is a postcondition?
Suggested answer: A condition that should be true after an operation completes successfully.
11. What is a representation invariant?
Suggested answer: A condition that must remain true for the internal state to represent a valid ADT instance.
12. How is a representation invariant different from an operation contract?
Suggested answer: The invariant concerns internal state validity across operations; a contract describes the behaviour of a particular public operation.
13. What is encapsulation?
Suggested answer: Bundling state with the operations that manage it while controlling direct access to the representation.
14. Why can exposing internal fields be dangerous?
Suggested answer: Clients can bypass validation and violate invariants.
15. What is information hiding?
Suggested answer: Hiding design decisions or internal details that clients do not need and that may change.
16. What is modular design?
Suggested answer: Structuring a system as components with focused responsibilities and controlled interfaces.
17. Explain high cohesion.
Suggested answer: A module's parts are closely related and contribute to one focused purpose.
18. Explain low coupling.
Suggested answer: A module depends on as few details of other modules as possible.
19. List the main steps in designing an ADT.
Suggested answer: Identify the concept/state, define operations, write contracts, state invariants, separate public/private responsibilities, choose an implementation and test through the interface.
20. Give one real application of abstraction and identify interface and hidden implementation.
Suggested answer: Example: an ML model exposes fit() and predict(); parameters, optimisation and internal numerical structures remain hidden.
