IS 237 · Topic 2

Review Questions

Try each question before opening the suggested answer.

1. What is data?
Suggested answer: Recorded values, facts or symbols that can be stored and processed.
2. What is a data object?
Suggested answer: A particular entity or instance that contains or represents data, such as one student record.
3. What is a data type?
Suggested answer: A classification that determines permitted values and meaningful operations.
4. Give four examples of built-in data types.
Suggested answer: Examples include integer, Boolean, floating-point, character and string.
5. What is meant by a derived or constructed type?
Suggested answer: A richer type or structure built by combining simpler values and associated operations.
6. Distinguish a data type from a data structure.
Suggested answer: A data type classifies values and operations; a data structure organises collections of values for efficient processing.
7. What is a linear data structure?
Suggested answer: A structure whose elements follow a sequential or one-dimensional logical order.
8. Give four examples of linear structures.
Suggested answer: Arrays, linked lists, stacks and queues.
9. What is a non-linear data structure?
Suggested answer: A structure in which elements can branch, form hierarchies or have many-to-many relationships.
10. Give two examples of non-linear structures.
Suggested answer: Trees and graphs.
11. Give one real-world example that naturally suggests a linear structure.
Suggested answer: Examples: people waiting in a queue, a playlist, or train carriages in sequence.
12. Give one real-world example that naturally suggests a non-linear structure.
Suggested answer: Examples: a family/organisation tree or a road network.
13. What is a static data structure?
Suggested answer: A structure whose relevant storage capacity is fixed or reserved in advance.
14. What is a dynamic data structure?
Suggested answer: A structure whose storage can grow or shrink while the programme runs.
15. Give the standard introductory example of a static structure.
Suggested answer: A fixed-size array.
16. Give the standard introductory example of a dynamic structure.
Suggested answer: A linked list.
17. Why is it misleading to say that a Stack is always dynamic?
Suggested answer: Stack describes ADT behaviour; it can be implemented using a fixed array or a dynamically growing linked representation.
18. What is abstraction in computer science?
Suggested answer: The deliberate hiding of unnecessary lower-level details so users work with essential behaviour.
19. Why does abstraction help manage complexity?
Suggested answer: It reduces the amount of detail considered at one time and allows reasoning through clear interfaces.
20. Define an Abstract Data Type (ADT).
Suggested answer: A logical description of values, permitted operations and behavioural rules independent of a specific representation.
21. What is the main difference between an ADT and a data structure?
Suggested answer: An ADT specifies what behaviour is provided; a data structure is a concrete representation used to implement it.
22. Can the same ADT have more than one implementation?
Suggested answer: Yes. Different data structures can satisfy the same ADT contract.
23. What is an interface?
Suggested answer: The public operations clients can use together with their expected behaviour.
24. What is an implementation?
Suggested answer: The hidden internal representation and procedures that make interface operations work.
25. Why is representation independence valuable?
Suggested answer: It allows internal implementation changes without forcing clients to change, provided the contract remains the same.
26. What is a precondition?
Suggested answer: A condition that must be true before an operation is validly called.
27. What is a postcondition?
Suggested answer: A condition that should be true after an operation completes successfully.
28. What is a representation invariant?
Suggested answer: A condition that must remain true for the internal state to represent a valid ADT instance.
29. How does encapsulation protect an ADT?
Suggested answer: It controls direct access to internal state and requires changes through operations that preserve the rules.
30. What do high cohesion and low coupling mean?
Suggested answer: High cohesion means a module has one focused purpose; low coupling means modules depend on minimal internal details of one another.
31. Why should implementation choice come after required behaviour is understood?
Suggested answer: Because the best representation depends on the operations, size and performance requirements of the problem.
32. Explain 'classroom seats' versus 'waiting list' as static/dynamic analogies.
Suggested answer: Classroom seats illustrate fixed capacity; a waiting list can grow or shrink as names are added or removed.
33. Explain how an ATM demonstrates abstraction.
Suggested answer: Customers use operations such as withdraw and balance without seeing database, authentication or transaction implementation details.
34. Explain how a road network illustrates a non-linear structure.
Suggested answer: One place can connect to several others, creating many possible paths rather than one sequence.
