# IS 237 — Data Abstraction and Algorithms

Welcome to the learning repository for **IS 237: Data Abstraction and Algorithms**.

**Institution:** Mkwawa University College of Education (MUCE), University of Dar es Salaam  
**Programme:** BSc in Data Science and Artificial Intelligence  
**Course status:** Core  
**Credit rating:** 12 credits  
**Total learning time:** 120 hours

## About the Course

IS 237 develops the ability to organise data, design algorithms, reason about correctness and efficiency, and choose suitable data structures for real problems. The learning materials combine detailed notes, pseudocode, visual traces, interactive animations, review questions, quizzes and application tasks.

A recurring course idea is:

> **Data Structure + Algorithm → Solution**

The learning approach is:

> **See it → manipulate it → explain it → trace it → formalise it.**

## Learning Outcomes

By the end of the course, students should be able to:

- describe basic data structures and algorithms;
- use algorithms in problem solving;
- create, modify, delete and combine data structures;
- apply data structures to implement user-defined data structures;
- compare the costs and benefits of dynamic and static data structures in relation to performance; and
- choose an appropriate data structure for modelling a given problem.

## Course Topics

1. **Problem Solving and Introduction to Algorithms**  
   Solution design, verification, problem-solving strategies and introductory efficiency.

2. **Data Abstraction and Abstract Data Types**  
   Abstraction, ADTs, interfaces, implementation, encapsulation and modular design.

3. **Arrays and Linked Lists**  
   Fixed and dynamic arrays; singly, doubly and circular linked lists; core operations and pseudocode.

4. **Stacks, Queues, Deques and Circular Queues**  
   LIFO/FIFO behaviour, implementations, circular storage and applications.

5. **Recursion and Iteration**  
   Recursive methods, call stacks, recursive patterns, tail recursion, iteration and trade-offs.

6. **Searching, Sorting and Algorithm Efficiency**  
   Big-O, time/space complexity, case analysis, linear and binary search, and major sorting algorithms.

7. **Trees, Binary Search Trees, Heaps and Hash Tables**  
   Tree traversals, BST operations, heaps, priority queues, hashing and collision handling.

8. **Graphs and Graph Algorithms**  
   Graph representations, BFS, DFS, connected components and weighted shortest paths.

## How to Use the Learning Site

For each topic:

1. Read the **Notes** to understand the concepts and pseudocode.
2. Use **Explore & Animate** to see operations and algorithms change step by step.
3. Attempt the **Quick Checks** before revealing the answers.
4. Work through the **Review Questions**.
5. Complete the **formative Quiz** and review weak areas.
6. Read the **Assignment** or application task and follow the current course instructions.
7. Use **Presentation Mode** when a concise visual recap is helpful.

The site stores topic-completion and quiz progress in the browser on the device being used. Clearing browser storage or changing devices may reset that local progress.
