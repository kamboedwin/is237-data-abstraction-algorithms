Data Abstraction and Algorithms

Learn how data is organised, how procedures operate on it, and how to reason about correctness and efficiency. The course uses detailed notes, visual traces and interactive animations before formal algorithm writing.

Course principle

See it → manipulate it → explain it → trace it → formalise it.

Course Roadmap

Why this order?

The topics are arranged as a learning progression so that each new idea builds on concepts and data structures introduced earlier.

Spiral approach

Begin with problem solving and algorithmic thinking, then move through abstraction and concrete data structures. Recursion follows stacks so the call stack can be visualised clearly. Searching, sorting and Big-O are then studied in depth before moving to advanced structures and graphs.

Problem→Algorithm→Abstraction→Structures→Algorithms on structures→Advanced structures
